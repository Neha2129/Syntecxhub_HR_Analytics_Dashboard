# HR Analytics Dashboard

## Project Overview
This project analyzes employee data to understand attrition patterns, salary distribution, job roles, departments, experience, overtime, and job satisfaction.

## Objectives
- Analyze employee attrition
- Identify factors related to attrition
- Compare attrition across departments and job roles
- Analyze salary and experience patterns
- Calculate attrition and retention rates
- Build an interactive HR dashboard

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- MySQL
- Power BI

## Key Analysis
- Attrition by Department
- Attrition by Job Role
- Attrition by Overtime
- Attrition by Job Satisfaction
- Average Salary by Department
- Employee Attrition & Retention KPIs
- Correlation Analysis

## Dashboard KPIs
- Total Employees
- Attrition Count
- Attrition Rate
- Retention Rate
- Average Salary

## Dataset
IBM HR Analytics Employee Attrition & Performance dataset.
